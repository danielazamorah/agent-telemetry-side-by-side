Agent telemetry · side by side

Drop two traces. See what is the same and what is not.

Every agent framework here writes OpenTelemetry: a tree of spans with ids, parents and timestamps. What differs is the dictionary of attribute names (OpenTelemetry GenAI gen_ai.* vs OpenInference) and where the words go. Load any traces (and, optionally, the session data) and compare. Everything runs in your browser; nothing is uploaded anywhere.

Drop JSON files here or
Reads: this repo's capture.py output · OTLP JSON (resourceSpans / resourceLogs) · OpenTelemetry console or JSONL span dumps · BigQuery exports of _AllSpans (JSON or JSONL) · Cloud Trace API traces (spans[].labels) · ADK session JSON (events[]) · LangGraph checkpoint state (values.messages). Files with spans become a trace; a session file is attached to the trace with the same name prefix, or to the last trace.
